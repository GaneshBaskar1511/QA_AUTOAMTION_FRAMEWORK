# QA Automation Framework

This repository is used for QA Automation Training.

Students will develop and submit their automation frameworks using their own technology stack.

Supported examples:
- Python + Playwright + Pytest
- Java + Selenium + TestNG
- TypeScript + Playwright
- Python + Selenium + Pytest

## Workflow

1. Create a student branch
2. Develop the automation framework
3. Commit changes
4. Push the branch
5. Create a Pull Request
6. Trainer reviews the code
7. Student fixes review comments
8. Trainer approves and merges the Pull Request
